# Collectables discovery

## Confirmed rules

Coin-owned DB collections; all valid flips (including Flip Off) have a 50% drop chance. Conditional rarity odds: Common 60%, Uncommon 25%, Rare 12%, Legendary 3%. Duplicates automatically evolve 3:1 through three levels. Optional mutually agreed pre-match wagers stake one sticker per coin; winner receives both, tie/cancellation returns originals. Wagers lock stickers against reuse and evolution until match ends. Artwork uses sibling `../recard RTG` project scripts. User requests one question at a time. Drop evolution level remains open.
